# การส่งออกข้อมูลให้หน่วยงานรัฐ

ระบบเพิ่มเมนู **ส่งออกข้อมูลหน่วยงานรัฐ** ในงานทะเบียน โดยยึดลำดับการทำงานจากหน้า SISA ที่ใช้งานจริง:

1. เลือกรูปแบบ/หน่วยงานปลายทาง
2. เลือกปีการศึกษาและภาคเรียน
3. เลือกหลักสูตร/สาขา (ไม่เลือกหมายถึงทุกหลักสูตร)
4. เลือกสถานะนักศึกษาในรูปแบบที่เกี่ยวข้อง
5. ตรวจความพร้อม ดูจำนวน ปัญหา และตัวอย่างข้อมูล
6. สร้าง CSV เมื่อไม่มีข้อผิดพลาดที่ขัดขวางการส่งออก

## รูปแบบที่มี

- ข้อมูลมาตรฐาน (นักศึกษา ตารางเรียน/ตารางสอน ผลการเรียน)
- GPA61
- SP48 / PSIS
- GPA สพฐ.
- กระทรวงการอุดมศึกษา วิทยาศาสตร์ วิจัยและนวัตกรรม
- SchoolMIS
- REGIS: นักศึกษา/ผลการเรียน บุคลากร และหลักสูตรวิชา
- PVIS และ PVRS
- ศธ.02
- Unicon

API อยู่ที่ `/api/v1/government-exports` โดย `catalog` ใช้สร้างตัวเลือก, `preview` ใช้ตรวจความพร้อม และ `generate` ใช้สร้างไฟล์ การสร้างไฟล์จำกัดสิทธิ์เฉพาะงานทะเบียน วิชาการ ผู้อำนวยการ และผู้ดูแลระบบ พร้อมเขียน audit event ชนิด `government_export`.

## ขอบเขตการรับรอง

ไฟล์ที่ระบบสร้างในรุ่นนี้เป็น CSV adapter สำหรับตรวจสอบและนำไปแปลงตามช่องข้อมูลของปลายทาง หน้าจอและการแบ่งชุดข้อมูลอ้างอิง SISA แต่ยังไม่ควรระบุว่าเป็นไฟล์ทางการที่อัปโหลดได้ทันที จนกว่าจะทดสอบกับคู่มือ schema หรือไฟล์ตัวอย่างของหน่วยงานในรุ่นปัจจุบัน เพราะหน้า SISA ไม่แสดงรายละเอียด byte-level ของไฟล์ก่อนดาวน์โหลดข้อมูลจริงของนักศึกษา
