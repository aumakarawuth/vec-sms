# ผลตรวจเทียบ SISA กับระบบใหม่จากการใช้งานจริง

วันที่ตรวจ: 12 สิงหาคม 2569  
ระบบต้นทาง: `ctc.sisacloud.com`  
ระบบใหม่: `localhost:5174`  

## ขอบเขตและวิธีตรวจ

- ตรวจด้วยบัญชีครูที่ล็อกอินอยู่ใน SISA และบัญชี `teacher.demo` ในระบบใหม่
- ค้นหานักศึกษาด้วยรหัส `20413` ตามที่กำหนด
- ทดสอบเฉพาะการอ่าน การค้นหา การเปลี่ยนตัวกรอง และการเปิดหน้าจอ ไม่กดบันทึก อนุมัติ ส่งเกรด หรือสร้างข้อมูลจริง
- สถานะ “มี” หมายถึงพบหน้าจอและ workflow ที่ใช้งานได้ ไม่ได้ดูแค่ชื่อตารางในฐานข้อมูล
- ฟังก์ชันหลังบ้านของระบบใหม่ที่บัญชีครูมองไม่เห็น อ้างอิงจาก route และหน้าจอที่มีอยู่ในโครงการ โดยแยกจากสิ่งที่ตรวจผ่าน UI จริง
- ไม่บันทึกข้อมูลส่วนบุคคลละเอียดของนักศึกษาลงรายงานนี้

## บทสรุป

ระบบใหม่ยังไม่ใช่ตัวแทน SISA แบบครบทุกโมดูล แต่แกนงานทะเบียนและงานครูบางส่วนทำได้ดีและมีกฎข้อมูลเข้มกว่า SISA ในหลายจุด

| มิติ | ผลตรวจ |
|---|---|
| ข้อมูลจริง | **ยังไม่พร้อม** — SISA พบ `20413` แต่ระบบใหม่ไม่พบ |
| งานครูประจำวัน | **พร้อมบางส่วนถึงค่อนข้างดี** — สมุดคะแนน เช็คชื่อ คำร้องแก้เกรด ความเสี่ยง พฤติกรรม ใบลา และทวิภาคี |
| งานทะเบียน | **มีแกนหลัก** — ระเบียน ลงทะเบียน เอกสาร สำเร็จการศึกษา รับสมัคร และนำเข้า แต่ยังขาดเครื่องมือย่อย/รายงานหลายชนิด |
| การเงิน | **มี workflow หลัก** แต่ยังไม่เท่าระบบบัญชีและรายงานของ SISA |
| บุคลากร | **มีแกน HR** แต่ยังขาดสวัสดิการ บัตร รูปภาพ โครงสร้างองค์กร การประเมิน และรายงานละเอียด |
| ระบบรอบข้าง | **ขาดมาก** — LMS คลังข้อสอบ สารบรรณ กิจกรรม การประเมิน และ report designer |
| ความพร้อมแทน SISA | **ยังไม่พร้อม cut-over** จนกว่าจะย้ายข้อมูลจริงและปิดช่องว่างระดับ P0/P1 |

## ผลทดสอบนักศึกษา 20413

### SISA

- ค้นพบ 1 รายการ
- แสดงระดับชั้น ห้อง ประเภทวิชา สาขา/กลุ่มอาชีพ หลักสูตร และปีการศึกษา
- เปิดแฟ้มนักศึกษาได้
- แฟ้มมีเมนูระดับบน: ข้อมูลส่วนตัว ตารางเรียน ทะเบียนวัดผล การลงทะเบียน ตรวจจบ การเงิน ค่าธรรมเนียม การยืมบิล เรียนเสริม/ปรับเกรด กองทุน พฤติกรรม และตั้งค่าเวลา
- แฟ้มส่วนบุคคลมี: แฟ้มสะสมผลงาน ข้อมูลนักศึกษา ที่อยู่/ผู้ปกครอง สุขภาพ การรักษา ใบสมัคร รายงาน ประชาสัมพันธ์ ศิษย์เก่า และไฟล์แนบ
- ข้อมูลหลายส่วนแก้ไขได้จากหน้าเดียวและมีปุ่มบันทึก

### ระบบใหม่

- ค้นหา `20413` แล้วแสดง `0 รายการ`
- จึงยังเทียบค่ารายฟิลด์ ประวัติการลงทะเบียน ผลการเรียน การเงิน และเอกสารของคนเดียวกันไม่ได้
- ระบบใหม่มีหน้าระเบียนนักศึกษาสำหรับข้อมูลตัวอย่าง และจากโครงการมีแท็บข้อมูลทั่วไป ที่อยู่ บิดามารดา สุขภาพ การศึกษาเดิม ที่ปรึกษา และการเรียน แต่ยังไม่ได้พิสูจน์กับข้อมูลจริง `20413`

### ข้อสรุปด้านข้อมูล

นี่เป็น blocker หลักก่อนใช้งานจริง ต้องมี data migration/reconciliation อย่างน้อย `person`, `student`, ประวัติสถานะ, ห้องเรียน, การลงทะเบียน, ผลการเรียน, เวลาเรียน, การเงิน, ผู้ปกครอง, สุขภาพ และเอกสาร โดยเทียบยอดและสุ่มตรวจรายคนกับ SISA

## สิ่งที่ระบบใหม่มีเด่นกว่าหรือ SISA ไม่มีตรงตัว

- Multi-tenant isolation และ platform administrator แยกจากผู้ดูแลวิทยาลัย
- กฎสิทธิ์เขียนระดับฐานข้อมูลและ audit trail ที่ทดสอบเป็นระบบ
- MFA, password reset, rate limiting และ production configuration guard
- Early-warning score และเคสติดตามพร้อม SLA
- ทวิภาคี: สถานประกอบการ MOU ใบส่งตัว ชั่วโมงฝึก และการรับรอง
- คำร้องแก้เกรดแบบผู้อนุมัติสองคนและเก็บเหตุผล/เลขเอกสาร
- เอกสาร snapshot ที่ออกแล้วแก้ย้อนหลังไม่ได้ พร้อมเลขเอกสารและสองภาษาในหลายชนิด
- การลาที่กระทบ attendance แบบมีกฎป้องกันการเขียนทับหลักฐานการมาเรียน
- API/OpenAPI และ automated database/API security tests เหมาะกับการเชื่อมระบบอื่น

## ช่องว่างเร่งด่วน

### P0 — ต้องทำก่อนย้ายใช้งาน

1. ย้ายและกระทบยอดข้อมูลจริง โดย `20413` ต้องค้นเจอและประวัติสำคัญตรงกับ SISA
2. สร้าง reconciliation report สำหรับยอดนักศึกษาต่อปี/ห้อง/สถานะ การลงทะเบียน เกรด เวลาเรียน และยอดลูกหนี้
3. ตรวจ role matrix ด้วยบัญชีจริงของครู ทะเบียน วิชาการ การเงิน ปกครอง ผู้อำนวยการ และ admin
4. ทดสอบเอกสารที่ต้องใช้จริงทุกแบบกับข้อมูลจริง รวมเลขที่ ภาษาไทย/อังกฤษ และการพิมพ์
5. ยืนยัน workflow เกรดตั้งแต่กรอก ส่ง อนุมัติ ล็อก แก้เกรด จนออกใบผลการเรียน

### P1 — จำเป็นต่อการแทนงานหลัก

1. ไฟล์แนบ รูปนักศึกษา และหลักฐานรับสมัคร
2. รายงานปฏิบัติการหลัก: รายชื่อ ห้อง สถานะ เข้า/ออก ขาด/ลา/สาย ผลเรียน และค้างชำระ
3. เครื่องมือรับชำระ/ใบเสร็จ/ธนาคาร/ลูกหนี้ให้ครบตามวิธีทำงานจริง
4. งานบุคลากรที่ใช้จริง: เวลา การลา อบรม สวัสดิการ ใบอนุญาต และรายงาน
5. ตารางสอบ เรียนเสริม สอบซ่อม สอนแทน และรายงานภาระงาน
6. การนำเข้าและส่งออกข้อมูลหน่วยงานรัฐที่วิทยาลัยต้องส่งจริง

### P2 — เลือกทำหรือเชื่อมระบบอื่น

- LMS และห้องสอบออนไลน์
- คลังข้อสอบและวิเคราะห์ข้อสอบ
- สารบรรณอิเล็กทรอนิกส์
- ระบบแบบประเมิน
- กิจกรรม/ประกาศนียบัตร
- บัตร RFID/เครื่องสแกน

ระบบใหม่เหมาะสำหรับเดินหน้าทดลองงานทะเบียนและงานครูแบบ parallel run แต่ยังไม่ควรปิด SISA การทดสอบรอบถัดไปควรนำข้อมูลจริงชุดเล็กหนึ่งห้องเข้าระบบใหม่ แล้วให้ครูคนเดิมทำงานคู่ขนานหนึ่งรอบ: เช็คชื่อ กรอกคะแนน ส่งเกรด ออกเอกสาร และตรวจยอดการเงิน ก่อนขยายทั้งวิทยาลัย
