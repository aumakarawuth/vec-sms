# ไฟล์ตัวอย่างใบ รบ. จากระบบจริง

PDF ในโฟลเดอร์นี้ออกจาก SISA ของวิทยาลัย ใช้เป็น**ต้นแบบที่วัดได้**
สำหรับทำแม่แบบการพิมพ์ — ผลการวัดอยู่ใน
[`docs/transcript-formats.md`](../docs/transcript-formats.md)

**ไฟล์เหล่านี้มีข้อมูลนักศึกษาจริง** — เลขประจำตัวประชาชน วันเกิด
ชื่อบิดามารดา และผลการเรียนรายวิชา เข้าเงื่อนไขข้อมูลส่วนบุคคลตาม PDPA

- ห้ามคัดลอกค่าจากไฟล์เหล่านี้ลงในโค้ด เทสต์ หรือข้อมูลตัวอย่าง
- ห้ามส่งออกนอกเครื่องพัฒนา (มาตรา 28 ถ้าออกนอกประเทศ)
- เอกสารที่สรุปผลการวัดบันทึกเฉพาะ**โครงสร้าง ตำแหน่ง และชื่อช่อง**
  ไม่มีค่าของใครอยู่ในนั้น

เมื่อทำแม่แบบครบแล้ว ควรลบโฟลเดอร์นี้ทิ้ง หรือแทนด้วยไฟล์ที่ปกปิดข้อมูลแล้ว
